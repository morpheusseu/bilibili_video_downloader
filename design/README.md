## 在桌面下载器中的应用

- 单一蓝色用于操作和焦点；白色卡片、浅灰画布、近黑正文，不使用装饰渐变或阴影。
  按用户后续要求，账号圆形入口的“登录”使用粉色，收藏入口使用黄色星形；
  这两处是明确的语义例外，不改写上游设计原文。
- 系统字体，不分发 SF Pro；标题 34px / 600，章节 21px / 600，正文与控件 14px，辅助文字 12px。
  桌面工具需要的信息密度高于营销网页，因此不复制大幅摄影、全屏宣传区或 56px 标题。
- 采用 18px 卡片圆角、8px 工具控件圆角、胶囊式主要操作，以及 8/12/20/24/32px 的间距节奏。
- 小号辅助文字使用略深的 `#6e6e73`，优先保证浅色背景上的可读性。
- 保留原生窗口与键盘操作，主要按钮固定在底部；760×650 小窗口通过滚动访问表单。
- 主线为“内容来源 → 保存设置 → 下载”。账号、Cookie、FFmpeg 路径与操作日志渐进展开，
  不用多页面向导阻止匿名下载。
- 预览是可读的内容列表，不再只有日志；改变来源或分 P 后立即清除旧预览，不自动请求。
- 任务区明确区分准备、处理中、完成、取消和失败，完成进度保留到下一次操作。
  下载期间始终区分视频流（画面）与音频流（声音），不把流的数量表述成视频数量。
  参考文档没有覆盖工具类错误状态，这里使用清楚的文字与恢复入口，不靠颜色表达结果。

视觉样式集中在 `bili_downloader/theme.py`，布局与任务反馈在 `bili_downloader/gui.py`；
不会引入 WebView、远程字体或新的 UI 框架。请求节奏、账号和下载引擎仍保持各自唯一 owner。

## 验证

`tests/test_gui.py` 使用真实 Qt 界面与后台线程，外部数据为合成响应：验证预览、切换选项、
下载参数、取消、错误恢复、凭证保存失败，以及窄窗口下的操作可达性。
视觉验收检查默认、账号展开、预览、错误及窄窗口状态；真实账号登录仍需用户完成官方验证。
